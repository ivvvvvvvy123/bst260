The syntax y ~ a * b - 1 for numerical y and factor variables a and b is described as fitting “first-order interactions”. Subgroups of individuals are formed for every combination of factor levels, and the mean value of y is computed for each subgroup. The -1 suppresses an intercept term.

R uses a peculiar naming convention for the estimated parameters. Race3Asian is used to show that the factor level for Race3 is Asian. Sexmale has a coefficient. This indicates to us that the ‘reference’ sex is female. Finally colon is used for combinations of factor values. We can recover the mean value for Black males by adding the coefficients for Race3Black, Sexmale, and Race3Black:Sexmale.

Observed counts are the actual number of people in each cell(each age decade and race combination). Expected counts are the counts we expect if the age decade and the race are independent. To form expected counts, we first find the total number of people in each age decade(row) and the total number for each race(column), and we multiply the row and the column and divide by the total number of participants(n), then we get the expected count for each cell.

A model for fairness

Intuitions

For a fair die with thorough tossing and replacement, each side has the same chance of landing face up.

In 2000 independent tosses, the expected number of appearances of each face is 2000/6(333.33).

Formalism

Formally, we can abstract from the actual names of the die and represent the tossing procedure in this way:

Let \(i = 1, \ldots, 6\) denote 6 sides.

Let \(j = 1, \ldots, 2000\) denote tosses.

Define

\[C_{ij} = \begin{cases} 1 & \text{if toss } j \text{ results in face } i, \\ 0 & \text{otherwise.} \end{cases}\]

Now define \(X_i = \sum_j C_{ij}\). Our statement above about the intuitive expectation on the number of appearances of any given number will be written \[EX_i = 2000/6 \text{ for all } i = 1,\ldots, 6.\]

This is equivalent to the following formulation. Let \(p_i, i=1, \ldots, 6\) denote the probability (not yet defined in any formal way) that our toss procedure yields number \(i\). Then \(EX_i = 2000 p_i\) for all \(i\). For the general case of \(n\) tosses, \(EX_i = n p_i\).

Measuring departure from fairness

A well-established metric for assessing departure from fairness is called “chi-squared”. We will use the symbol \(D\) to represent this measure. Large values of \(D\) can be indicative of departure of the observed frequencies from the expected values.

\[D = \sum_{i=1}^{6} \frac{(X_i - EX_i)^2}{EX_i}\]

We’ll implement \(D\) as mystat and show that it is equivalent to a quantity computed in R with chisq.test.

mystat = function(dat, expected) {
  sum((table(factor(dat, levels = 1:6)) - expected)^2 / expected)
}
ExpectedCount = 2000/6
sum((table(drs)-ExpectedCount)^2/ExpectedCount)
[1] 8.326
chisq.test(table(drs))

    Chi-squared test for given probabilities

data:  table(drs)
X-squared = 8.326, df = 5, p-value = 0.1392
mystat(drs, ExpectedCount)
[1] 8.326

Note that chisq.test reports the same statistic as mystat, but includes values for df (degrees of freedom) and p-value. “Degrees of freedom” refers here to the fact that we have a fixed number of count categories (6 numbers), and if 5 are known, the value for the 6th can be deduced – it is “unfree”.

For a fair die, the expected frequency of each face is 2000/6. The chi-squared has 5 degrees of freedom due to six categories and fixed total number of tosses.

The p-value is a quantity that, when small, can be indicative of a departure from the expected outcome of an experiment. We will return to that concept at a later date.

Replicating our test of fairness many times

Any given collection of toss events will yield a value of \(D\). Different series will yield different values of \(D\), but when the die is fair, the variation in \(D\) is prescribed by the mathematics of probability.

We will make a histogram of 100 replicates of 2000 tosses to exhibit variation in \(D\).

set.seed(1234)
predist = lapply(1:100, function(x) replicate(2000, toss_die(die))) #replicate 100 times exp. each exp rolls the die 2000 times.
dist = sapply(predist, function(x)mystat(x, expected=2000/6)) #calculate each experiment's chi-square
hist(dist, prob=TRUE) # for histogram of 100 replicates.

With 1000 replicates, we get a more pleasing display.

set.seed(1234)
predist = lapply(1:1000, function(x) replicate(2000, toss_die(die)))
dist = sapply(predist, function(x)mystat(x, expected=2000/6))
hist(dist, probability=TRUE)

The form of this histogram (drawn in R with the probability argument set to TRUE) can be approximated by the density of the chi-squared distribution with 5 degrees of freedom.

hist(dist, probability=TRUE) # y axis is density
lines(1:100, dchisq(1:100, 5)) # generate integer from 1 to 100 for x axis.

The “5” fixes the degrees of freedom of the model for which the density will be drawn.

Interpret

What’s the difference between these two runs?

set.seed(1234)
baddie = die
baddie[1] = 6
newdrs = replicate(2000, toss_die(baddie))
mystat(newdrs, ExpectedCount)
[1] 704.158
set.seed(1234)
baddie[2] = 6
newdrs = replicate(2000, toss_die(baddie))
mystat(newdrs, ExpectedCount)
[1] 1949.95

They both use the same seed 1234. The difference is the first run has an unfair die, where the probability of 6 is 2/6(1/3), and the second run has a worse unfair die, where the probability of 6 is 3/6(1/2). For the first run, the counts are 0 for face 1, against the expected 333.33 for each face, which gives D=704.158. For the second run, the counts are 0 for both face 1 and 2, giving D=1949.95. The more unfair die produces the larger D. The We may have a larger chi-squared statistic, which show how the chi-squared statistic measures discrepancies between observed and expected frequencies.
